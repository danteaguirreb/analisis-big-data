# Análisis de Big Data — Magíster en Data Science UDD

Laboratorios seleccionados del curso, organizados por sesión y con las salidas ejecutadas retiradas para que cada notebook pueda revisarse y ejecutarse en un entorno propio.

## Laboratorios

1. Repaso práctico de Spark.
2. Benchmark Spark, DuckDB y Polars.
3. Calidad de datos y feature engineering distribuido.
4. Pipelines de ML distribuido y MLflow.
5. Recomendadores ALS y búsqueda semántica con embeddings.
6. Streaming con Kafka, Structured Streaming y ventanas.
7. Marca de agua, alertas y equidad.

Cada notebook puede requerir datasets públicos, librerías o servicios descritos dentro del propio material. Los datos, entornos de ejecución, archivos de clase y soluciones ajenas no se distribuyen aquí.
